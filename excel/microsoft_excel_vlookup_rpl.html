MEMAHAMIANATOMI RUMUS VLOOKUP
=VLOOKUP(A2,$E$2:$H$6,3,FALSE)
Lookup value — nilai kunci yang dicari Table array — rentang tabel referensi (dikunci dengan $) Col index num — kolom ke berapa hasil diambil Range lookup — FALSE untuk pencocokan persis

Lookup value

Data yang ingin kamu cari, contoh: kode perangkat lunak IDE-01.

Table array

Seluruh tabel referensi tempat data dicari, dari kolom kunci hingga kolom hasil.

Col index num

Posisi kolom hasil dihitung dari kolom pertama tabel referensi, mulai dari angka 1.

Range lookup

FALSE mencari kecocokan persis; TRUE mencari nilai mendekati.

SIGNATURESIMULATOR VLOOKUP — DATA PERANGKAT LUNAK

Pilih kode perangkat lunak, lalu jalankan rumus. Perhatikan bagaimana VLOOKUP menelusuri kolom kunci ke bawah, berhenti tepat saat menemukan kecocokan, lalu bergeser ke kanan mengambil hasil.

MENGAPLIKASI · 60'PROJECT BASED LEARNING

  • Bentuk kelompok kolaboratif berisi 2–3 orang.
  • Setiap kelompok menerima jobsheet/LKPD Project VLOOKUP.
  • Bagi peran: pencari data, penulis rumus, dan pemeriksa hasil.

  1. Guru mendemonstrasikan cara menulis rumus VLOOKUP langsung di Excel.
  2. Murid mengamati posisi tanda $ pada table array.
  3. Murid mencoba menirukan pada data latihan masing-masing.

  • Kerjakan seluruh soal pada jobsheet/LKPD secara berkelompok.
  • Periksa kembali peralatan dan file kerja sebelum mengumpulkan.
  • Uji rumus dengan mengganti kode perangkat lunak untuk memastikan hasil selalu benar.
