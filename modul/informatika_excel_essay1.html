Microsoft Excel dalam pekerjaan Admin HRD

Lima pertanyaan dan jawaban tentang mengelola data karyawan, absensi, rekap kehadiran, penggajian, dan pengelompokan per divisi.

1Jelaskan bagaimana Microsoft Excel dapat membantu seorang Admin HRD dalam mengelola data karyawan di sebuah perusahaan!

Excel menyimpan data karyawan dalam bentuk tabel yang rapi: satu baris untuk satu karyawan dan satu kolom untuk satu jenis data. Dengan begitu, Admin HRD dapat mencari, mengurutkan, menyaring, dan memperbarui data dengan cepat.

  • Penyimpanan terstruktur. Kolom seperti NIK, nama, jabatan, divisi, tanggal masuk, dan status kepegawaian disusun dalam satu tabel.
  • Sort dan Filter. Data bisa diurutkan menurut nama atau tanggal masuk, dan disaring menurut divisi atau status.
  • Rumus otomatis. Masa kerja, usia, atau tanggal berakhir kontrak dihitung otomatis sehingga tidak perlu dihitung manual.
  • Data Validation. Isian dibatasi lewat daftar pilihan (misalnya divisi) untuk mencegah salah ketik.
  • Pencarian cepat. Fungsi VLOOKUP atau XLOOKUP menampilkan data lengkap karyawan dari NIK-nya.

Contoh rumus menghitung masa kerja (tahun) dengan tanggal masuk di kolom F:

=DATEDIF(F2; TODAY(); "Y")

=XLOOKUP(A2; Data!A:A; Data!B:B; "Tidak ditemukan")

2Bagaimana cara menggunakan Microsoft Excel untuk membuat daftar absensi karyawan setiap bulan?

Langkah pembuatannya:

  1. Buat sheet baru dan beri nama sesuai bulan, misalnya Januari. Bulan berikutnya cukup menyalin sheet tersebut.
  2. Isi kolom A dengan No, kolom B dengan NIK, dan kolom C dengan Nama Karyawan.
  3. Mulai kolom D, isi tanggal 1 sampai 31 sebagai judul kolom. Tanggal bisa dibuat otomatis dengan rumus.
  4. Isi sel absensi dengan kode: H (hadir), I (izin), S (sakit), A (alpa/tidak hadir). Gunakan Data Validation agar hanya kode itu yang bisa dimasukkan.
  5. Tambahkan kolom total di sebelah kanan untuk menjumlahkan tiap kode.
  6. Gunakan Conditional Formatting supaya kode berwarna berbeda (misalnya A berwarna merah) dan mudah dikenali.
Tanggal otomatis (sel D4 = tanggal 1 bulan itu, E4 dst.):
D4: =DATE(2026; 1; 1)
E4: =D4+1

Daftar pilihan Data Validation (Allow: List):
H,I,S,A

3Seorang Admin HRD diminta menghitung jumlah karyawan yang hadir, izin, sakit, dan tidak hadir. Bagaimana Excel dapat membantu menyelesaikan pekerjaan tersebut?

Excel menghitung rekap kehadiran secara otomatis memakai fungsi COUNTIF. Fungsi ini menghitung berapa kali sebuah kode muncul pada rentang sel. Admin tidak perlu menghitung satu per satu, dan hasilnya langsung berubah saat data absensi diperbarui.

Rekap per karyawan (absensi di D5:AH5):

Hadir      : =COUNTIF(D5:AH5; "H")
Izin       : =COUNTIF(D5:AH5; "I")
Sakit      : =COUNTIF(D5:AH5; "S")
Tidak hadir: =COUNTIF(D5:AH5; "A")

Rekap seluruh karyawan pada satu hari tertentu (kolom D):

=COUNTIF(D5:D54; "H")
=COUNTIF(D5:D54; "I")
=COUNTIF(D5:D54; "S")
=COUNTIF(D5:D54; "A")

Hasilnya dapat divisualisasikan dengan grafik (misalnya pie chart) untuk laporan kepada pimpinan.

4Jelaskan bagaimana penggunaan Microsoft Excel untuk membuat tabel penggajian karyawan yang berisi gaji pokok, tunjangan, potongan, dan total gaji!

Tabel penggajian dibuat dengan kolom: No, Nama, Gaji Pokok, Tunjangan, Potongan, dan Total Gaji. Gaji pokok diinput, sedangkan tunjangan, potongan, dan total dihitung otomatis dengan rumus. Jika ada perubahan data, seluruh hasil ikut diperbarui.

Rumus dengan contoh baris 5 (C = Gaji Pokok, D = Tunjangan, E = Potongan, F = Total Gaji):

Tunjangan (misal 10% dari gaji pokok):
D5: =C5*10%

Potongan (misal BPJS 3% dari gaji pokok):
E5: =C5*3%

Total gaji:
F5: =C5+D5-E5

Total seluruh pengeluaran gaji:
F20: =SUM(F5:F19)

5Jika seorang Admin HRD ingin mengetahui jumlah karyawan berdasarkan divisi atau bagian pekerjaan, bagaimana Microsoft Excel dapat digunakan untuk mengolah data tersebut?

Ada dua cara yang umum digunakan.

1. Fungsi COUNTIF. Cocok untuk daftar divisi yang sudah tetap. Jika kolom divisi ada di D2:D100:

=COUNTIF(D2:D100; "Keuangan")
=COUNTIF(D2:D100; "Produksi")
=COUNTIF(D2:D100; H2)    // H2 berisi nama divisi

2. PivotTable. Cara paling cepat dan fleksibel:

  1. Blok seluruh tabel data karyawan.
  2. Pilih menu Insert lalu PivotTable.
  3. Tarik field Divisi ke area Rows.
  4. Tarik field Nama (atau NIK) ke area Values dengan fungsi Count.

Hasilnya adalah tabel jumlah karyawan per divisi yang dapat diubah menjadi grafik batang atau pie chart.
